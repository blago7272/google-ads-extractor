# Report Pages

## Overview

Backed by:

- `mart_ads_overview_daily`
- `mart_ads_overview_monthly`
- `mart_ads_alerts`

Main outputs:

- spend
- clicks
- impressions
- conversions
- conversion value
- CPA
- ROAS
- CTR
- CPC

## Campaign Explorer

Backed by:

- `mart_ads_campaign_daily`

Main outputs:

- campaign trends
- cost and conversions
- channel type
- bidding strategy
- budget context

## Keyword Audit

Backed by:

- `mart_ads_keyword_audit_detail`
- `mart_ads_search_terms`

Main outputs:

- spend with zero conversions
- low QS opportunities
- bid/rank opportunities
- low volume keywords
- search term waste candidates

## Budget And Daypart

Backed by:

- `mart_ads_budget_exhaustion`
- `mart_ads_adgroup_daypart`

Main outputs:

- campaigns exhausting budget early
- hourly pacing curve
- day vs night ad group profile

## Alerts

Backed by:

- `mart_ads_alerts`

Main outputs:

- consolidated actions list with severity
- direct links into the underlying page or table
